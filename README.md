# Zivich Research Group

This GitHub contains a collection of resources built for my lab group.

## Group Meetings

My group meetings are a 1.5-hour meeting with all my students expected to attend that occurs weekly during the Fall and 
Spring semesters. The structure of these meetings is
- 5 minutes for continuing education piece (relevant slides live in `presentations/`)
- 5 minutes for each attendee to briefly state what they would like to discuss that week (to help me triage)
- The remaining 80 minutes for individual-specific discussion

Occasionally we might modify the 80 minutes to discuss a paper we have collectively read or allot for time from a guest
attendee. 


## Materials

- `presentations/`: folder containing continuing education presentations from group meetings
- `resources/`: folder containing relevant group-specific resources mentioned elsewhere in documents
