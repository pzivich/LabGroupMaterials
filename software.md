# Suggested Software

The following is some suggested software for different topics. Note that this should not be viewed as mandatory or
must have programs. These are instead general recommendations for software that covers different research tasks.

## Record Keeping

- [Obsidian](https://obsidian.md/): a general note-taking app. It allows for different projects and linking notes 
together. Importantly, everything is stored as plain text files so files can be accessed oustide of Obsidian
- [Zotero](https://www.zotero.org/): how I organize the papers I read and manage references for my manuscripts. There is
a free option. Has integration with browsers to simplify downloading citations and with Word for referencing.
- [TeXStudio](https://www.texstudio.org/): the LaTeX editor I use for manuscripts and slides. While Overleaf is popular,
this has been my preference.
- [GitHub Desktop](https://desktop.github.com/download/): this is how I manage my GitHub commits and branches. I learned
via the terminal, but this is a much friendlier option to use (without anything you are missing out on from the 
terminal)

## Data Analysis

There is no requirement for what software program you use. My personal experience covers SAS, R, Python. Below is a few
recommended IDEs for coding

- [PyCharm](https://www.jetbrains.com/pycharm/): the Python IDE I use. It is free and has support for other file types
- [RStudio](https://posit.co/products/open-source/rstudio): the R IDE I use. Again, it is free
